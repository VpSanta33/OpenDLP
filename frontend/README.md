# OpenDLP 前端 · 企业数据防泄漏管理平台

零依赖的纯前端控制台（HTML + CSS + 原生 JS），无需构建。数据与权限全部来自 Go 后端（`../backend`），由后端同源托管。

## 运行

前端由 Go 后端同源托管，需要 PostgreSQL。启动方式与首次初始化见 [后端 README](../backend/README.md)，生产部署见 [deploy](../deploy/README.md)。

> 前端依赖后端的 Cookie 会话与 API，直接双击 `index.html` 打开无法使用。

## 登录与权限

首次访问进入**系统初始化**（初始化令牌 + 创建超级管理员 + 绑定 MFA）。之后登录使用 **账号口令 + TOTP 动态码**；暂不支持企业 SSO 与扫码登录。

菜单、页面数据与按钮按当前角色的权限矩阵收敛（等保 2.0「三员分立」），越权访问显示 403 页；**所有权限均由后端强制校验**，前端仅负责展示。

## 功能模块

| 分组 | 页面 | 路由 | 对接的后端能力 |
| --- | --- | --- | --- |
| 监控中心 | 安全态势总览 | `#/dashboard` | 按小时聚合的检测统计、环比、风险评分、热力图；SSE 实时事件流 |
| | 事件告警 | `#/incidents` | 服务端分页筛选、处置 / 误报、批量处置、AI 研判、CSV 导出 |
| | 用户风险画像 | `#/ueba` | 基于近 30 天事件计算评分、行为维度（对比部门基线）与异常行为；观察名单（高危以外的事件也实时告警）、严格管控（终端审计升级为阻断） |
| 数据防护 | 策略管理 | `#/policies` | 新建策略（服务端校验）、启停 |
| | 识别规则库 | `#/rules` | 自定义规则 RE2 校验、测试沙箱由服务端识别（含身份证校验位、Luhn） |
| | 敏感数据发现 | `#/discovery` | 登记数据源，汇总外部扫描工具通过上报接口回传的对象数与分级结果（不内置扫描器） |
| | 外发审批 | `#/approvals` | 审批状态机（有部门负责人时先经负责人再到安全管理员、驳回必填意见、超时自动关闭）、转交、批量审批；提交方可查询审批结果 |
| 资产与合规 | 终端管理 | `#/endpoints` | 终端由 Agent 注册与心跳自动登记；推送策略、远程扫描以指令形式下发，Agent 心跳时领取；吊销凭据、终端接入指引 |
| | 报表中心 | `#/reports` | 服务端生成 HTML / CSV 报告、定时报表、历史归档下载 |
| | 审计日志 | `#/audit` | 服务端分页、SHA-256 哈希链完整性校验、导出 |
| 系统管理 | 组织与权限 | `#/iam` | CSV 导入组织架构、权限矩阵（三员分立冲突校验）、管理员（初始口令与 MFA 绑定只显示一次） |
| | 运维与集成 | `#/ops` | 节点心跳指标、实时健康检查（数据库 / SSE / 任务 / 节点）、集成连通性测试、许可与版本、诊断、配置快照 |
| | 系统设置 | `#/settings` | 读取 / 保存服务端配置（审计日志保留期不得少于 180 天） |

全局能力：下载中心（后端异步任务）、通知中心、`⌘K / Ctrl K` 命令面板、界面偏好（主题 / 导航栏风格 / 主题色 / 密度）、屏幕安全水印（当前账号与登录 IP）、响应式布局。

## 目录结构

```
frontend/
├── index.html          # 应用外壳
├── css/style.css       # 设计令牌（浅/深主题）、组件与动画
└── js/
    ├── boot.js         # 首帧前应用主题（独立文件以满足 CSP）
    ├── icons.js        # 线性图标集
    ├── data.js         # 数据容器：由 /api/v1/bootstrap 填充
    ├── api.js          # API 客户端（Cookie 会话、CSRF 头、错误处理、SSE）
    ├── charts.js       # 轻量 SVG 图表库
    ├── core.js         # 公共 UI 与事件总线、act() 请求封装
    ├── app.js          # 登录、权限、路由、下载中心、通知、命令面板
    └── pages/          # 各业务页面（html() 渲染 + mount() 绑定交互）
```
